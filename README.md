# VertigoLab — Playbook Pintar, Interaktif & Makmal Klinikal Vertigo

Aplikasi web interaktif dan edukatif untuk memahami anatomi vestibular, mekanisme biologi vertigo, saringan kecemasan strok (HINTS & 5D), pelaksanaan fizikal Epley Maneuver, strategi pemulihan VRT, dan latihan keputusan klinikal.

## Modul Utama
1. **Simulator Konflik 3 Sensor & Bebola Mata (*Nystagmus*)**
2. **Makmal Anatomi Telinga Dalam (*Otoliths*, *Stereocilia*, *Semicircular Ducts*)**
3. **Matriks Pintar 5 Punca Utama & Enjin Triaj Kebarangkalian**
4. **Simulator Saringan Strok Kecemasan (Protokol HINTS & Amaran 5D)**
5. **Simulator Fizikal 5 Langkah Epley Maneuver + Pemasa Klinikal**
6. **Lengkung Pemulihan Otak (`< 72 Jam`), Jurulatih VRT & Kalkulator Natrium Meniere**
7. **3 Analogi Visual Mudah Hadam + 5 Senario Kuiz Klinikal**

## Menjalankan Secara Lokal
Buka `index.html` terus menggunakan pelayar web moden (Google Chrome, Edge, Firefox, Safari).

## Deployment ke Cloudflare Workers
Repositori ini dilengkapi `wrangler.jsonc` dan `.assetsignore` untuk *Workers Static Assets*. Sambungkan repositori GitHub ini terus melalui **Cloudflare Dashboard → Workers & Pages → Create → Import a repository**.
